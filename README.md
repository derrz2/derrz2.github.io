# Wenhao Ye

Personal academic website: https://derrz2.github.io/

A static website built with HTML, CSS, and JavaScript. Published with GitHub Pages from the `main` branch.

## Local preview

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Edit `index.html` for content, `styles.css` for layout, and `script.js` for navigation.

The decorative background in `ambient-network.js` follows the particle interaction shown on https://chengkunli96.github.io/: 99 freely drifting points, short distance-based connections, and immediate attraction of nearby existing particles towards the mouse. There are no extra orbiting points or idle delay. Line weights, opacity, connection distances, and attraction strength are matched to that reference. Visitors can pause the animation; reduced-motion preferences and hidden tabs stop rendering. No external animation libraries are required.
